# USAAIO Training

> Personal training repo for the **USA AI Olympiad** — Gold medal 2025, requalified for Round 2 in 2026.

---

## Background

The [USA AI Olympiad (USAAIO)](https://www.usaaio.org/) is the premier national AI competition for students in the United States. Top performers advance to the [International Olympiad in Artificial Intelligence (IOAI)](https://ioai-official.org/), the global stage for AI problem-solving.

USAAIO tests both **mathematical theory** and **from-scratch implementation** — contestants must derive formulas by hand *and* code them in Python/PyTorch, often without high-level APIs.

## Curriculum overview (2026)

The 12 units build progressively from foundations to competition-ready skills:

```
Foundations               ML & PyTorch              Deep Learning & Advanced
─────────────            ──────────────            ─────────────────────────
01 Markdown              04 Supervised Learning    07 Deep Learning
02 Math Foundations      05 Unsupervised Learning  08 NLP
03 Python Programming    06 Programming PyTorch    09 Transformers
                                                   10 Computer Vision & GenAI
                                                   11 Graph Neural Networks
                                                   12 AI Grandmaster
```

**Round 1** covers Units 01–07. **Round 2** covers the full range, Units 01–12.

See [`2026/units/README.md`](2026/units/README.md) for the detailed unit table, dependency graph, and competition milestone mapping.
