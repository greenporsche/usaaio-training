# USA AI Olympiad — 2025 Official Problems

Contest problems and official solutions from the 2025 [USA-NA-AIO](https://www.usaaio.org/2025-usa-na-aio).

- **Round 1** — March 24, 2025 (at school) — 3 problems, 300 points, 3 hours
- **Round 2** — April 27, 2025 (MIT) — 3 problems, 300 points

Discussion forum: <https://forum.beaver-edge.ai/c/ai-olympiads/5>

---

## Round 1

| Problem | Topic | Type |
|---------|-------|------|
| 1 (100 pts) | Fibonacci & Eigendecomposition — recurrence relations, spectral decomposition, closed-form derivation | Math + NumPy |
| 2 (100 pts) | Neural Network Basics — affine transformations, gradients, symmetric networks, ReLU, MLP training | Math + PyTorch |
| 3 (100 pts) | Data Science Pipeline (Titanic) — data loading, exploration, preprocessing, modeling | Pandas + ML |

Files:

- `round1/problem-{1,2,3}.ipynb` — contest problem notebooks
- `round1/USAAIO_2025_round1_prob3_train.csv` — training dataset for Problem 3
- `round1/round1-solutions/Problem_{1,2,3}_Solution.ipynb` — official solutions
